# Bash

Bash is what allows the terminal to understand your inputs and execute commands based off of those inputs. 

**bashrc** refers to the source file within your computer that tells bash how 
it can act, including being able to customize it. For example, with **bashrc**,
you can:
- Create aliases for commands: alias ll = 'ls -l', which allows for convenience
- Customize settings for editors like Vim. Having a Git repo saves this info

# Terminal

The terminal is the window that allows you execute bash commands.
